# 日本交換選校圖

給義守大學應用日語學系的學弟妹規劃日本姐妹校交換時參考：12 所姐妹校的位置、門檻、每月花費、課程和附近地點，學校對比，申請條件和資格自我檢查，按入學學年推算的時間表，47 個都道府縣的知名地點，以及雙學位、生活方面的資料。

應日系學生整理，非官方資料，以系辦和各校公告為準。資料截至 2026-11-24。

- 繁體版是 index.html，簡體版是 hans.html，頁面上方可以切換。
- 申請條件、資格自我檢查和時間表照應用日語學系 2026 年日本姐妹校交換的甄選規定（114.12.29 系務會議通過）；之後的規定可能不同。
- 資格自我檢查填的內容只在瀏覽器裡計算，不儲存，也不送出。
- 地圖輪廓來自 amCharts 4 geodata（japanHigh），授權說明見 https://github.com/amcharts/amcharts4-geodata/blob/master/LICENSE ，頁面底部有署名。
- 照片來自 Wikimedia Commons，每張的作者和授權寫在頁面裡的照片下方。
- 文字資料的出處都在頁面裡各節的「來源」。
