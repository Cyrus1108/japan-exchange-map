# 日本交换选校图

义守大学应用日语学系日本姐妹校的地图整理：12 所姐妹校的位置、门槛、每月花费、课程和附近地点，47 个都道府县的知名地点，申请条件，以及双学位、生活方面的资料。学校资料截至 2026-11-20，申请条件截至 2026-11-23，双学位与生活资料截至 2026-11-21。

- 地图轮廓来自 amCharts 4 geodata（japanHigh），授权说明见 https://github.com/amcharts/amcharts4-geodata/blob/master/LICENSE ，页面底部有署名。
- 照片来自 Wikimedia Commons，每张的作者和授权写在页面里的照片下方。
- 文字资料的出处都在页面里各节的「来源」。
- 内容是个人整理，以各校和义守大学公布的为准。
